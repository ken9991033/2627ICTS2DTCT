# 花階磚設計工作室

中二級資訊及通訊科技科「設計與計算思維」（上學期課次 5、6）的互動學習平台。

學生會為一位用家設計一塊香港花階磚，過程中經歷設計思維（同理、定義、構思、原型、測試），同時學習計算思維（拆解、模式識別、抽象化、演算法），最後匯出 STL 檔，用學校的 3D 打印機打印成杯墊、迷你磚或鎖匙扣。

教學建議、主題選擇、評估量表及 3D 打印安排見 **[docs/教學設計建議.md](docs/教學設計建議.md)**。

## 八個步驟

| 課次 | 步驟 | 設計思維 | 計算思維 | 學生會做甚麼 |
|---|---|---|---|---|
| 5 | 1 認識用家 | 同理 | 收集資料 | 揀一張用家卡，模擬訪問，從答案中找出最少 3 個需要 |
| 5 | 2 定義問題 | 定義 | 抽象化 | 揀產品，排出 3 個最重要的需要，寫出「我們可以如何……？」 |
| 5 | 3 花階磚偵探 | 定義 | 拆解、模式識別 | 找出最小重複單位（1/8、1/4）；把大問題拆成三類小任務 |
| 5 | 4 演算法工作坊 | 構思 | 迴圈、條件、除錯 | 用 Scratch 式積木重複、旋轉、鏡像；捉蟲；巢狀迴圈及「如果」拼地板 |
| 6 | 5 設計花階磚 | 構思、原型 | 抽象化、演算法 | 在「基本區域」放形狀，電腦按對稱規則完成整塊磚；儲存 v1 |
| 6 | 6 3D 原型 | 原型 | 數據表示 | 把顏色轉成高度，檢查尺寸、打印時間及太幼的部分，下載 STL |
| 6 | 7 測試與改良 | 測試 | 測試、迭代 | 同學扮演用家評分及給意見；按意見修改並儲存 v2 |
| 6 | 8 作品卡 | 分享 | 反思 | 反思及創作聲明；下載作品卡（PNG）、STL 及存檔（JSON） |

右上角的「教師工具」有課堂流程及計時器、全班作品牆（匯入學生存檔，砌成「全班地板」，並一次過輸出打印盤 STL）及答案。

## 開啟方法

**方法一：網上版（建議）**
把這個 repository 放上 GitHub Pages（Settings → Pages → 選擇分支 → Save），學生用瀏覽器開啟網址即可。也可以把整個資料夾放到學校網站伺服器。

**方法二：離線單一檔案**
`dist/hk-tile-studio.html` 已包含所有程式（連 three.js），不用上網。複製到學生電腦或共用磁碟，用 Chrome 或 Edge 雙擊開啟即可。

**方法三：直接開啟資料夾**
下載整個資料夾，雙擊 `index.html`。`lib/three.min.js` 必須放在旁邊。

建議使用 Windows 的 Chrome 或 Edge。學校電腦如有還原系統（重開機會清除資料），請提醒學生在第一課完結前按「存檔 → 下載存檔」，並上載到 Google Classroom／Teams；第二課再用「載入存檔」繼續。

## 修改內容

所有文字內容都在 **`js/content.js`**，不用懂程式也可以修改：

- `personas`：用家卡及訪問答案。答案中用 `[[文字|需要代號]]` 標記可以收集的「需要」
- `needs`：需要清單（`auto` 代表電腦可自動檢查）
- `palette`：顏色
- `products`：產品尺寸、底座厚度、凸起高度（毫米）
- `presets`：範例磚
- `feedback`、`learned`、`declarations`：測試意見、反思及創作聲明選項
- `lessons`、`teacherTips`：教師工具中的課堂流程及提示
- `options.allowRandom`：評估時可設為 `false`，關閉「隨機靈感」

修改後重新整理網頁即可。如使用離線單一檔案，請執行 `python3 tools/build.py` 重新生成 `dist/hk-tile-studio.html`。

## 檔案結構

```
index.html            頁面結構
css/style.css         樣式（淺色及深色模式）
js/content.js         內容設定（老師可修改）
js/engine.js          繪圖引擎：形狀、對稱、地板拼法、隨機靈感
js/mesh.js            3D 模型：顏色遮罩 → Marching Squares 輪廓 → 立體 → STL／ZIP
js/view3d.js          three.js 3D 預覽
js/app.js             核心：狀態、儲存、導航、開始頁
js/steps-learn.js     課次 5：步驟 1–4
js/steps-make.js      課次 6：步驟 5–8
js/teacher.js         教師工具
lib/three.min.js      three.js r149（MIT 授權）
tools/build.py        生成離線單一檔案
dist/                 生成的檔案
docs/                 教學設計建議
```

## 3D 打印

- 匯出的 STL 以毫米為單位、Z 軸向上，可直接放入 Bambu Studio、PrusaSlicer、Cura 等切片軟件，不需支撐。
- 建議設定：PLA、層高 0.2 mm、填充 15–20%。
- 雙色效果：在切片軟件於「底座厚度」的高度（杯墊 2.4 mm、迷你磚 2.0 mm）加入暫停／換料。
- 多色打印機：下載「分色模型（ZIP）」，把所有 STL 作為同一物件的多個部件匯入，再逐一指定顏色。
- 全班迷你磚：在「教師工具 → 全班作品牆」匯入學生存檔，下載打印盤 STL（220 mm 打印盤一次最多 25 件）。

## 私隱

平台不需登入，不會把任何資料傳到網上。學生的進度只儲存在該部電腦的瀏覽器（localStorage）及學生自己下載的存檔內。

## 技術

純 HTML、CSS、JavaScript，不需要安裝或編譯。3D 預覽使用 [three.js](https://threejs.org/)（r149，MIT 授權）。字體使用 Google Fonts 的昭源黑體／昭源圓體（未能連線時會改用微軟正黑體）。
